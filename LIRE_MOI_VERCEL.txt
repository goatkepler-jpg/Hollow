NOCTURNE — VERCEL / hollowsound.store

Ce ZIP est un projet statique pour Vercel, avec une fonction API Meta.
Ne pas le déployer comme un projet Cloudflare ou Netlify.

CONTENU
index.html           : site NOCTURNE (HTML allégé, même apparence)
audio/*.mp3          : sept extraits audio séparés, mêmes données originales
nocturne-background.mp3 : musique d'ambiance
og-nocturne.jpg, nocturne-cover.jpg : images pour SEO et réseaux sociaux
api/meta-capi.mjs    : fonction Meta CAPI sur Vercel, sans jeton
robots.txt, sitemap.xml : référencement hollowsound.store
vercel.json          : cache des médias statiques

DÉPLOIEMENT
1. Décompresser le ZIP et placer TOUS les fichiers dans le projet Git de Vercel.
2. Garder les fichiers à la racine (index.html et vercel.json), avec les sous-dossiers.
3. Dans Vercel : Framework Preset « Other », aucune commande de build nécessaire.
4. Déployer en production sur le projet EXISTANT relié à hollowsound.store.
5. Dans Settings > Environment Variables, ajouter META_CAPI_ACCESS_TOKEN
   comme variable confidentielle pour Production ; redéployer.
6. Tester /, /audio/m1.mp3, /nocturne-background.mp3, /sitemap.xml.
7. GET /api/meta-capi doit répondre 405 ; Meta Events Manager peut contrôler les événements.
8. Dans Settings > Domains, confirmer les DNS recommandés et le certificat HTTPS.
9. Soumettre https://hollowsound.store/sitemap.xml dans Search Console.

IMPORTANT
La musique audible nécessite normalement un clic (« Enter the night ») sur Chrome.
Meta PageView et InitiateCheckout ne sont pas des achats confirmés.
Ne jamais publier le jeton de conversion dans HTML/JavaScript client.
Le ZIP ne garantit pas à lui seul que le domaine fonctionne chez tous les internautes.
